# Vowel Counter

A simple **Vowel Counter** built using Python.
This beginner-friendly project counts the number of vowels present in a word or sentence.

## Features

- Accepts a word or sentence from the user
- Counts vowels automatically
- Supports uppercase and lowercase letters
- Displays the total number of vowels
- Simple and beginner-friendly

## Technologies Used

- Python
- Strings
- `for` loop
- `if` statement
- `lower()` method
- `in` operator

## Concepts Learned

- Working with strings
- Loops
- Conditional statements
- String methods
- Counters
- User input
- Basic text processing
